## Create a page

<Steps>
1. Create a Markdown file in `src/content/docs/start/`.
2. Add a `title`, `description`, and optional sidebar order in frontmatter.
3. Commit your changes. The build generates pages and a search index.
</Steps>

## Add images

Add images to the project and reference them with Markdown image syntax. Provide accurate alternative text for accessibility.
